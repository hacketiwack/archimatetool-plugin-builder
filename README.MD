# Introduction

This repository contains a builder for [Archi](https://github.com/archimatetool) plugins, which are not readily available for download.

Currently, the plugins being built are:

- [jArchi](https://github.com/archimatetool/archi-scripting-plugin) - The Archi Scripting Plugin
- [coArchi2](https://github.com/archimatetool/archi-modelrepository-plugin2) - Archi Model Collaboration Plugin

The built artifacts are available [here](https://github.com/hacketiwack/archimatetool-plugin-builder/releases/tag/snapshot).
